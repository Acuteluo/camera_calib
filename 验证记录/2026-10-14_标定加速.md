# 标定求解加速验证

代码基线：`6592737`（修复全新环境部署、标定保存与 ACE JSON 导出）。
环境：系统 `/usr/bin/python3 -s`，OpenCV 4.9.0；真实图片验证使用 2 个 OpenCV 线程。

## 改动

`calibrate_mono.calibrate()` 默认为 `cv2.calibrateCamera` 添加 `CALIB_USE_QR`，
把大量视图的线性求解由 SVD 改为 QR。每张图片都有 6 个待求位姿参数，191 个视图
会形成一千多个参数的联合优化；默认 SVD 在这次真实数据上耗时很长。

全部样本、角点精修、畸变模型、默认收敛条件和坏帧剔除规则保持原样。
调用者已经明确指定 QR 或 LU 时沿用该选择。GUI 和纯 OpenCV 命令行共同使用此函数。

## 191 张真实图片

原始数据：`标定结果/20261013_205527_hik_11x8/frames/`，1440×1080，
11×8 内角点，25 mm 方格。原目录的图像、YAML、报告和 ACE 配置均未改写。

离线验证先从保存的 PNG 重建 480px 预览角点，再调用真实 GUI 的
`calibrate_samples()`，包含全分辨率精修和原有离群判定。

| 项目 | 结果 |
|---|---:|
| 历史 GUI 标定用时（20:25:57 至 20:48:31） | 22 分 34 秒 |
| 从 PNG 读取图片并重建预览角点 | 12.224 秒 |
| 新版角点精修与标定 | 34.693 秒 |
| 其中 191 视图 QR 联合求解 | 33.010 秒 |
| 图片预处理与标定合计（不含后续分析及报告写出） | 46.917 秒 |
| 新版 RMS | 0.138000 px |
| 原报告 RMS | 0.1375 px |
| fx/fy 最大相对变化 | 0.034611% |
| cx/cy 最大绝对变化 | 1.064 px |
| 720 个全画面网格点的去畸变校正变化：平均 / 最大 | 0.04179 / 0.25636 px |

新版内参：fx=2431.38266，fy=2428.83633，cx=702.24980，cy=544.99650。
新版畸变：[-0.04655862, 0.05079573, -0.00110421, -0.00043100, 0]。

原结果剔除 1 张，保留 190 张；离线重建角点的新版结果保留 191 张。
原 GUI 的预览角点未保存，故重建的角点输入并非逐点相同；这部分精度变化包含角点
重建与离群判定的差别。整体 RMS、焦距与去畸变校正变化均在本轮可接受范围内。
原 GUI 触发了剔除坏帧后的第二次求解，本次离线重算只求解一次；历史运行的线程设置与
并发负载也没有完整记录。因此 22 分 34 秒与 34.693 秒是运行耗时参考，不能作为严格
同条件的求解器加速倍数。相同输入的求解器对照见下一节。

## 同一组 191 张角点的独立重投影核对

重新取得同样的 191 张精修角点（共 16,808 个点），固定原 YAML 内参或新版 QR 内参，
逐张独立使用 `solvePnP` 求位姿，再用 `projectPoints` 重算误差；不再运行联合标定。
以下 RMS 采用所有角点的平方误差总和计算，分母为角点数。

| 固定内参 | 所有角点 RMS | 最大单张 RMS |
|---|---:|---:|
| 原保存内参 | 0.13805137 px | 0.50566208 px |
| 新版 QR 内参 | 0.13800020 px | 0.50562197 px |

新版在相同真实角点上的重投影误差未增大，独立重算的 RMS 也与联合求解结果
0.13800011 px 一致。此检查验证相同观测数据的拟合效果；实际姿态精度没有外部真值。

## 同一组角点的求解器对比

从以上真实角点中均匀选取 20 个视图，直接比较旧 SVD 与新版 QR，隔离角点输入差异。

| 项目 | 结果 |
|---|---:|
| SVD 单次用时 | 0.398 秒 |
| QR 单次用时 | 0.063 秒 |
| RMS 绝对差 | 1.11e-16 px |
| 内参最大绝对差 | 5.01e-7 px |
| 畸变系数最大绝对差 | 7.85e-11 |

Luna 另外验证了 20 个多姿态、含 0.2px 噪声的合成视图；QR 与 SVD 的 RMS、内参、
畸变及逐视图误差在数值精度范围内一致。

## 对照发现与修复

| 基线问题 | 修复后行为 |
|---|---|
| GUI 海康使用系统新 SDK，CLI 仍可能加载随包 3.2.1 | 两个入口共用 SDK 环境；三厂修复版的头文件、链接库、运行库保持同一套 |
| 海康只枚举 USB，等待无设备可无限循环 | 同时枚举 USB/GigE；检查返回码，无匹配或多匹配明确报错 |
| 三厂默认取第一台，可能标错设备 | 单台自动选、多台按序列号唯一选择；报告记录实际打开的型号与 SN |
| 三厂 reserve 后即传 data()，帧尺寸/有效容量不一致 | 按当前帧尺寸先分配有效缓冲区，再进行 SDK 转换 |
| 大恒仅彩色 Bayer8；参数设置成功判断反了 | 选取相机支持的 Bayer8/Mono8；修复回调成功判断，转换失败不发布错误画面 |
| 迈德威视构造提前返回后仍释放未初始化句柄，运行库来自系统缓存 | 保护句柄/失败清理；将构建对应的 SDK 安装至独立运行目录 |
| 换型号可能保留外触发，曝光增益范围不同，灰度机没有彩色节点 | 连续采集/关闭触发；读取设备实际曝光/增益及范围，灰度机跳过 RGB 增益与饱和度 |

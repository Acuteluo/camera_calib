# 相机 udev 权限修复（需要 root，一次即可）

## 为什么要修

三个相机都不走 UVC，普通用户默认没权限直接访问 USB 设备。本机的规则有三个毛病：

| 文件 | 问题 | 后果 |
|---|---|---|
| `/etc/udev/rules.d/88-mvusb.rules` | 内容被**截断损坏**，行尾是 `A"` / `R"`（原文应是 `RUN+="..."`） | 整行 udev 解析失败，迈德威视的 `f622` 规则不生效 |
| `/etc/udev/rules.d/99-mvusb.rules` | 引用了**不存在的用户组** `mvusb_dev` | 组解析失败（MODE 仍可能生效，但不干净） |
| `/etc/udev/rules.d/99-galaxy-u3v.rules` | 海康 `2bdf` 被 `MODE:="0660"` + `plugdev` **锁死**（`:=` 是最终赋值，后面的规则改不动它） | 必须重新登录让 plugdev 组生效，否则打不开相机 |

## 怎么修（在你自己终端里执行，需要 sudo）

```bash
cd ~/camera_calib/udev_fix
sudo ./install_udev.sh
```

脚本会：

1. 把要被覆盖的三个文件**先备份**成 `<原名>.bak.<时间戳>`；
2. 安装修好的规则（三个文件都在本目录里）；
3. 执行 `udevadm control --reload-rules` + `udevadm trigger --subsystem-match=usb`；
4. 打印验证方法。

修好后的关键变化：

```
88-mvusb.rules        迈德威视 f622 / 080b  ->  MODE="0666" + uaccess（不再依赖 RUN+ 脚本）
99-mvusb.rules        去掉不存在的 mvusb_dev 组 -> MODE="0666" + uaccess
99-galaxy-u3v.rules   大恒 2ba2     -> MODE:="0666"
                      海康 2bdf     -> MODE:="0666"（原来 0660 锁死，要重新登录）
```

## 验证

```bash
lsusb | grep -iE "2bdf|2ba2|f622"          # 找到相机
ls -l /dev/bus/usb/*/*                      # 对应设备应为 crw-rw-rw-
```

或者直接跑体检（会尝试打开 SDK）：

```bash
cd ~/camera_calib
./ros2_calibrate.sh check hik
./ros2_calibrate.sh check mv
```

## 只想临时用一次（不改系统）

```bash
newgrp plugdev        # 当前终端立即获得 plugdev 组（海康原来那条规则靠它）
```

## 不想改 / 改不了怎么办

* 桌面会话里规则带的 `TAG+="uaccess"` 通常已经能让**当前登录的用户**访问这些相机；
  `sudo` 只是把权限彻底放宽，省掉"重新登录"这类坑。
* 如果连 `sudo` 都用不了，先按上面的 `newgrp plugdev` 试；海康相机的
  `/etc/udev/rules.d/99-galaxy-u3v.rules` 里已有 `TAG+="uaccess"`。
